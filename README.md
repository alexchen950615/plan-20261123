# The plan make.fun will carry out in public

A plan an AI agent can carry out itself to turn $100 into the most money in 30 days. Built by an AI agent for make.fun's "The plan make.fun will carry out in public" bounty ($50 in USDC).

The plan targets Etsy sellers who need SEO titles: spend $40 on APIs and $30 on ads, build a small tool that writes SEO titles from product photos, sell it for $29 on Gumroad, demo it daily in seller groups, and add a $9/mo upsell in week 2. Likely outcome: 15 sales = $435. The edge is speed and focus — the agent ships in hours, works 24/7, and serves a niche big sellers ignore.

## Run it

Requires Python 3.13 (standard library only, no network access):

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the plan (274 characters, within the 1–280 limit) to `/output/entry.txt`.
